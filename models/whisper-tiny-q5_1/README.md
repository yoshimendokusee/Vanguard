# Whisper tiny multilingual model

`ggml-tiny-q5_1.bin` is the quantized multilingual OpenAI Whisper tiny model,
converted by the ggml-org `whisper.cpp` project. It supports English and
Filipino/Tagalog and runs offline on the Watch. The model is 31 MB; the smaller
file trades recognition accuracy for memory and app size. Users can correct the
transcript before report review.

Source: https://huggingface.co/ggerganov/whisper.cpp
Original model: https://github.com/openai/whisper
